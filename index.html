Slash and prefix

Almost every command works both ways. Use /, or . and takina  out of the box. Servers can pick their own prefix.

Moderation with a paper trail

Bans, kicks, mutes and warnings become numbered cases you can look up, edit and total up per moderator.

Free, forever

No premium features and no paywalls. Takina is licensed under AGPLv3, so you may read it, run it and improve it.

Built to be hosted

PostgreSQL, Docker, and a first-class NixOS module. Prefer to run your own copy? It takes a few minutes.

Run your own

Takina is written in Python on discord.py, backed by PostgreSQL. The README covers Nix flakes, Docker and Docker Compose. If you self-host, please read the Terms of Service first: they ask for a small note of attribution in your bot's bio.
